# مَدار — مراجعة مقياس المالية العامة

داشبورد عربية خفيفة لمراجعة المحاضرات الثماني ونماذج الإجابة المرفوعة. لا يحتاج المشروع إلى Docker أو Node.js أو قاعدة بيانات أو حساب مستخدم.

## التشغيل على جهازك

1. نزّل/استنسخ المستودع كاملًا إلى جهازك، بما فيه ملفات PDF.
2. افتح `index.html` بالنقر المزدوج، وسيعمل في Chrome أو Edge دون تثبيت.
3. إذا لم يحفظ المتصفح التقدّم عند فتح الملف مباشرة، افتح Terminal من مجلد المشروع في VS Code وشغّل:

   ```bash
   py -m http.server 8000 --bind 127.0.0.1
   ```

   ثم افتح `http://127.0.0.1:8000`. في الأنظمة التي لا تستخدم `py` استخدم `python3 -m http.server 8000 --bind 127.0.0.1`.

أوقف الخادم المحلي بـ `Ctrl+C`. لا يحتاج الداشبورد إلى الإنترنت أثناء الدراسة، ولا يرسل الملفات أو الإجابات إلى أي خدمة خارجية. تُحفظ علامات إكمال المحاضرات والبطاقات ونتائج الاختبار في تخزين المتصفح المحلي؛ تبقى خاصة بهذا المتصفح والجهاز.

## ما يتضمنه

- خريطة للمحاضرات مع خلاصة ونقاط أساسية وتعريفات ومراجع إلى صفحات PDF.
- بطاقات استرجاع نشط مع حفظ ما تم إتقانه.
- اختبار اختيار من متعدد مع تصحيح وشرح.
- تحليل لنمطي الإجابة النموذجية 2023–2024 و2024–2025، مع مخططات مراجعة وروابط إلى ملفات PDF الأصلية.
- بحث عربي بسيط داخل ملخصات المحاضرات وتعريفاتها ونماذج الإجابة.

المحتوى التعليمي مختصر للمراجعة؛ عند إعداد إجابة امتحانية، راجع ملف المحاضرة أو نموذج الإجابة الأصلي للصياغة الكاملة.

## الخصوصية

التطبيق نفسه محلي بالكامل. لكن رفع ملفات المحاضرات إلى مستودع GitHub عام يجعل ملفات PDF متاحة للعامة؛ اجعل المستودع خاصًا إذا لم ترد نشرها.
